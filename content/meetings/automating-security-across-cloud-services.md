Disruptive technology trends such as enterprise adoption of the cloud often drives the need to rethink security architectures. Enterprises as well as cloud providers have made tactical security improvements for individual cloud services. But, the rapidly increasing volume of cloud usage and the velocity of the changing threat landscape are forcing enterprises to abstract a layer of security across all cloud services.

This presentation will discuss the factors that enterprises need to consider in order to develop an effective security architecture for the cloud including:

- Holistic visibility across SaaS, PaaS and IaaS
- Complementing static security policies with machine learning
- Full lifecycle approach from threat detection to incident response
- Automation to achieve scale

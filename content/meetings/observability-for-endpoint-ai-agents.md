**Introduction**

AI coding assistants are becoming standard workplace tools. But when an AI agent runs commands on someone's device, what can security teams actually observe?

Join us for a practical look at endpoint observability for AI agents: the telemetry available today, where visibility still falls short, and what those gaps mean for security teams and emerging technology providers.

**Key Topics Covered**

* Security risks associated with AI coding assistants
* Best practices for reducing those risks
* Tools that can support detection and response
* What endpoint telemetry can—and can't—show about AI agent activity

**Why Attend**

Get a clearer view of the security questions raised when AI assistants act on users' devices. Take away practical risk-reduction ideas, learn what detection and response tools can help, and join fellow security professionals for discussion and networking.

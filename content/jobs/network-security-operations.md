**Qualifications:**

- Bachelor's degree in computer science, engineering or related discipline or commensurate experience
- Relevant certifications will rank candidates higher than other candidates
- Verbal and written communication skills must be exceptional
- Occasional weekend or holiday work may be required
- Some travel, to other company locations may be required in the future

**Scope of Work:**

- Network security operations to include next generation firewalls, web proxies, vulnerability management, intrusion detection, load balancing and systems associated with these devices such as monitoring and asset management
- Hands-on work with encryption, authentication, and identity architectures
- Implementation of network security for Cloud services and corporate networks
- Administration of network security systems to include security policies
- Anti-virus software, patch management systems, CASB and so on
- Network and host vulnerability hunting and threat intelligence tools
- Participation in security audits
- Incident response and post-incident analysis
- Working knowledge of SMTP and email security
- Managing Network Access Control frameworks
- In-depth knowledge of LAN and WAN

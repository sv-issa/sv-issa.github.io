We are actively seeking an experienced **Cyber Security Engineer** to join a rapidly growing startup. Well-funded and poised to double in size, this company's platform will transform how businesses interact.

**About the Position**

- Seeking a seasoned veteran in Cyber Security, been there-done that-seen it all mentality
- Key member of an enterprise-level cyber security team
- Ensure that applications, services and infrastructure are designed, implemented, and secured to the highest standards
- Incorporate security into company's infrastructure design and application design processes
- Keep company on the bleeding edge of security threats, vulnerabilities and controls
- 24x7 security operations center
- Face paced, entrepreneurial environment, do what it takes work ethic
- Use top notch security tools like SEIM, IDS / IPS, Firewalls, Anti-APT and other security

**Qualifications**

- Bachelor's degree is required.
- 4+ years of experience in Information Security in complex organizations.
- Experience with a variety of security technologies such as firewalls, anti-virus, IDS/IPS, vulnerability scanners, SIEM, etc.
- Understanding of the following protocols/technologies: SSL/TLS and Cryptography (symmetric and asymmetric encryption, PKI, etc.).
- Knowledge of web application vulnerability exploitation, analysis, and experience in mitigation strategies.
- Familiar with:
  - Networking concepts like routing, filtering, and proxy technologies. Should be able to work well with network teams when integrating security devices into the network and understanding network designs.
  - Systems administration concepts such as DNS, Active Directory, Web Servers, backups, and file-sharing methodologies. Should be able to work well with systems teams when integrating security processes into the server environment.

**Preferred Skills**

- Technical certifications, e.g. Certified Ethical Hacker, GIAC Certified Web Application Defender, GIAC Web Application Penetration Tester
- Juniper certification JNCIE, JNCIP, JNCIS, JNCIA
- Previous experience in a network or systems administration role
- Scripting/programming experience a plus
- Experience working in a financial institution or an electronic payments processing environment
- Experience with Cloud Services (SaaS, PaaS, IaaS), connected services, service-oriented architectures and web services

Support the operation of the DLP (Data Loss Prevention) program by collaborating with stake holders and business users in order to prevent leakage of sensitive information. Support the Security Operation Center (SOC) team in handling security alerts during the US time zone.

**Responsibilities:**

- Data Loss Prevention of structured and unstructured data inclusive of Data at rest, Data in motion, Data in use
- Develop, Create and test DLP rules.
- Discover sensitive data using DLP discovery tools.
- Fine tune rules to eliminate false positives
- Respond to DLP alerts
- Work with business in creating and fine tuning rules
- Respond to SOC alerts during US time zone
- Configuration of scanning and monitoring policies
- Monitoring and analysis of DLP alerts.
- Engineer and architect DLP solution.
- Deploy DLP solution and transition to production
- Monitor computer security events then take appropriate action based on documented procedures
- Escalate computer security events to the Incident Response Manager based on documented procedures
- Assist in driving computer security incidents to completion
- Create computer security metrics and dashboards

**Minimum Qualifications:**

- Bachelor's degree
- Knowlege of business and technical aspects of Data Loss Prevention
- U.S. Citizen
- Ability to obtain a Secret level U.S. Government clearance
- Detail oriented
